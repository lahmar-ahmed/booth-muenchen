# Booth München

DJ-Buchungsplattform für München: DJs finden und buchen, Plattenkiste (Vinyl & Tracks), Equipment & DJ-Studios mieten.

- Frontend: eine statische Seite (`index.html`), kein Build nötig
- Backend: Supabase (Datenbank, Login per E-Mail-Link, Zugriffsregeln)
- Datenbank-Schema: `supabase/schema.sql`

## Lokal ansehen
`index.html` im Browser öffnen.

## Deploy
Repo bei Vercel importieren, Framework „Other“, kein Build-Befehl. Fertig.
